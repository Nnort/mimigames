# Мимиигра

Обучающие мини-игры для Веры. Что и зачем — в [PLAN.md](PLAN.md).

## Запуск

```bash
npm install
npm run dev
```

Дальше открыть адрес, который напечатает Vite — обычно http://localhost:5173

## Что уже работает

- **Карта городка** — шесть локаций, открываются те, где есть игры
- **Механика `ask`** — «Угадай, что я загадал»: вопросы задаёт ребёнок
- **Механика `quiz`** — вопрос с вариантами ответа, два пака на чтение и понимание
- **Уровни поддержки** — движок из PLAN.md §2: поле вариантов сужается и расширяется само
- **Озвучка** — кнопка «прочитать вслух» на текстах, синтез речи Windows
- **Настройки** — звук, спокойный режим, размер букв
- **Панель для взрослых** — кнопка `···` справа вверху

## Перенести на другой компьютер

```bash
npm run portable
```

Собирает папку `portable/` — около 90 МБ, копируется на флешку целиком.
На том компьютере ничего устанавливать не нужно: внутри лежит `node.exe`,
запуск двойным кликом по `Играть.bat`.

Почему не просто открыть `index.html`: браузер считает файл с диска чужим источником
и запрещает `localStorage`, а в нём весь прогресс и уровни поддержки. Поэтому внутри
портативной версии крошечный локальный сервер — он и открывает браузер сам.

**Прогресс не переносится** вместе с папкой: он живёт в браузере того компьютера,
на котором играли.

## Посмотреть глазами

```bash
npm run dev     # в одном окне
npm run shot    # в другом
```

Прокликивает приложение, складывает экраны в `.shots/` и печатает ошибки консоли.
Использует системный Chrome, отдельный бинарник браузера не нужен.

## Добавить новую игру

Положить JSON в `content/quiz/`. Код править не нужно — паки подхватываются сами.
Формат — в [PLAN.md](PLAN.md) §8, примеры в `content/quiz/*.json`.

## Графика

Листы эмоций генерируются по промптам из [docs/prompts.md](docs/prompts.md),
дальше обрабатываются скриптами:

```bash
python tools/slice_sheet.py refs/vera1.jpg vera        # нарезать 3x2 на шесть спрайтов
python tools/cutout.py public/assets/characters/vera   # вырезать ровный фон
```

**Светлому персонажу нужен пониженный порог.** Заливка идёт от краёв и останавливается
там, где цвет отличается от фона сильнее порога. У Анджелы белая шерсть на светло-сером
фоне — разница мала, и на пороге по умолчанию заливка уходит внутрь головы:

```bash
python tools/cutout.py public/assets/characters/angela --thresh 16
```

Предметам вырезание фона **не нужно** — они уже на белом и лежат на белых карточках.
Их только нарезают, с явной сеткой, потому что границ панелей на белом листе нет:

```bash
python tools/slice_items.py refs/лист1.jpg --grid 3x2 --no-label --names ramen,marmalade,sausage,ball,balloon,slime
```

Фоны локаций кладутся в `public/assets/backgrounds/<id>.jpg`,
где `<id>` — `home`, `yard`, `school`, `shop`, `park`, `clinic`.

Требуется `pillow` (`pip install pillow`).

## Структура

```
src/core/       движок: паки, прогресс, уровни поддержки, озвучка
src/app/        оболочка: карта, рамка задания, настройки, панель для взрослых
src/mechanics/  механики, по папке на каждую
content/        контент-паки в JSON
public/assets/  спрайты персонажей и фоны
tools/          скрипты обработки графики
docs/           стайл-гайд и промпты
refs/           исходные референсы
```
